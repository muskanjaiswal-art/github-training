# Git Commands Reference

## 1. git init
Initializes a new Git repository.

Example:
```bash
git init
```

## 2. git clone
Copies a remote repository to your computer.

Example:
```bash
git clone git@github.com:username/repository.git
```

## 3. git status
Shows the current repository status.

Example:
```bash
git status
```

## 4. git add
Stages changes.

Example:
```bash
git add .
```

## 5. git commit
Creates a commit.

Example:
```bash
git commit -m "Initial commit"
```

## 6. git push
Uploads commits to GitHub.

Example:
```bash
git push
```

## 7. git pull
Downloads the latest changes.

Example:
```bash
git pull
```

## 8. git branch
Lists branches.

Example:
```bash
git branch
```

## 9. git switch
Switches branches.

Example:
```bash
git switch main
```

## 10. git checkout
Switches or creates branches.

Example:
```bash
git checkout -b feature/login
```

## 11. git merge
Merges one branch into another.

Example:
```bash
git merge feature/profile
```

## 12. git diff
Shows file differences.

Example:
```bash
git diff
```

## 13. git log
Displays commit history.

Example:
```bash
git log --oneline
```

## 14. git remote -v
Shows remote repositories.

Example:
```bash
git remote -v
```

## 15. git restore
Restores a file to its previous state.

Example:
```bash
git restore README.md
```
